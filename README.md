# workbench(段取りさん)

大学の授業・課題・就活・アルバイトと、自分の開発のやることと予定を、1つのアプリにまとめて管理するためのアプリ。画面を見れば次にやることがわかる、を目指しています。アプリの中にはキャラクターの「モッチ」がいて、話しかけると手伝ってくれます(作成中)。

要件定義 → 構想設計 → 基本設計 → UI試作 → 実装 → テストの順に進めていて、今は実装(要件 F1〜F22)がそろい、自分の PC で使って確かめているところです。進み具合は [docs/spec-excel-status.md](docs/spec-excel-status.md) を見てください。

- 設計書(要件定義書など)は本人が判断して作り、`docs/` に置いています
- 実装は、設計書をもとに AI(Claude)が担当します
- 各工程で AI が何を提案し、本人が何を決めたかは `docs/ai-log/` に残しています

## 開き方

- `段取りさんを開く.bat` をダブルクリックすると、本体が動いていなければ裏で動かし、Chrome の専用の窓で開きます(Chrome がないときは既定のブラウザ)
- 本体だけを動かすときは `run_server.bat`(ログは `run_log.txt`)
- 開くのはこの PC の中からだけです(`http://127.0.0.1:8780/`)

## 置き場所

| 場所 | 中身 |
|---|---|
| `app.py` | 本体(Flask) |
| `db.py` | データの表(SQLite) |

## メールの読み方

- 大学のメールは、PC の Outlook アプリ(クラシック版)を読み取りだけで10分ごとに読みます。大学のアドレスの形は、設定の「メールと連絡」で `data/` にだけ保存します
- 会社・アルバイトのメールは、自分の Gmail を Google の公式の連携(読むだけ)で10分ごとに読みます
  1. Google Cloud で「デスクトップ アプリ」の OAuth クライアントを作り、合鍵のファイルを保存する(無料)
  2. `python manage.py google-key <保存したファイル>` で、ID と秘密の文字を `.env` に移す
  3. 段取りさんの設定の「Google」で [Google と連携する] を押して許可する(通行証は `.env` に入る)
- `.env` は GitHub に上げません。見本は `.env.example`
- メールを送る・消す・既読にする・ラベルをつけることはしません

## git とシフト表

- 入れ物の設定に「リポジトリの場所」を入れると、git のコミットを10分ごとに読んで記録に並べます。git は読むだけです
- コミットのメッセージに「完了:」があると、そのリポジトリのタスクを Claude に選ばせて自動で完了にします。提出の受付メールも同じです。連絡の「自動で完了」から [戻す] で戻せます
- シフト表の写真は「予定」の画面に落とします。Claude(`claude -p`)には、写真1枚だけを置いた一時フォルダで「ファイルを読む」道具だけを渡し、読み終えたら写真ごと消します。シフト表での自分の名前は、設定の「メールと連絡」で `data/` にだけ保存します

## モッチと PC のファイル

- モッチが探して読めるのは、設定の「フォルダ」に登録したフォルダの中だけです(はじめは `Workspace` と `Downloads`。フォルダの選択の窓で足す・外す)。読むだけで、書きかえ・消す・動かすはしません(`localfiles.py`)
- `.env`・パスワードや鍵らしい名前のファイル・隠しフォルダ・`.git`・`node_modules`・段取りさんの `data/` は読みません。ファイルを開くのは、確認のカードを押したときだけで、動くファイル(.exe・.bat など)は開きません
- 読んだ中身はその会話の中で Claude に渡るだけで、段取りさんにはどのファイルを読んだかだけが残ります

## データの予備と戻し方

本体を起動したときと、本体が動いたまま日付が変わったとき(PC が眠りから起きた最初の1分など)に、その日の分がまだなければ `data/backup/` に `dandori-日付.db` を作り、7日分だけ残します。

戻すときは、本体を止めてから(タスクマネージャーで `pythonw` の app.py を終了)、`data/backup/` の戻したい日のファイルを `data/dandori.db` という名前でコピーして置きかえ、もう一度開きます。
