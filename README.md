# workbench(作業台)

大学でやっている作業(授業・課題・卒論)と、自分の開発を、1つの Web アプリでまとめて管理するためのアプリ。

いまは設計の段階です。要件定義 → 構想設計 → 基本設計 → UI試作 → 実装 → テストの順に進めています。進み具合は [docs/spec-excel-status.md](docs/spec-excel-status.md) を見てください。

- 設計書(要件定義書など)は本人が判断して作り、`docs/` に置いています
- 実装は、設計書をもとに AI(Claude)が担当します
- 各工程で AI が何を提案し、本人が何を決めたかは `docs/ai-log/` に残しています
