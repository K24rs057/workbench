## 説明できるようにしておきたい仕組み

- **この PC の中からだけ開ける:** 本体は 127.0.0.1 でだけ待ち受ける。同じ Wi-Fi のほかの端末からは届かない
- **予備が壊れない:** SQLite の backup 機能でコピーするので、書き込み中でも途中の形のファイルにならない
- **窓の名前だけを読む:** 画面の中身は見ず、前に出ている窓の名前とアプリの名前だけを1分ごとに読む。初めての窓は「覚える文字」(VS Code ならフォルダ名、Word ならファイル名)を取り出して聞き、答えたら窓の名前そのものは消す
- **眠っていた時間を数えない:** 前に読んだ時刻から3分以上あいていたら、眠っていたとみなして、前に読んだ時刻で記録を止める
- **モッチは道具を持たない:** claude -p に道具を1つも渡さず(--tools "")、データの要約だけを渡す。操作は「やりたいこと」の JSON で返させ、渡していない道具・ない番号は捨て、本人が確認のボタンを押したときだけ本体が行う
- **古い本体を残さない:** 画面を開く .bat は、本体のコードが新しくなっていたら古い本体を止めて動かし直す。同じポートで2つ目は動かさない
